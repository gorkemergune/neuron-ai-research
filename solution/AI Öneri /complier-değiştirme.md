# Overleaf Compiler Değiştirme

Projeyi doğru şekilde derlemek için Overleaf üzerinde **XeLaTeX** compiler kullanılmalıdır.

## Adımlar

1. Overleaf projesini açın.
2. Sol üst köşeden **Menu** butonuna tıklayın.
3. **Compiler** bölümünü bulun.
4. Compiler olarak **XeLaTeX** seçin.
5. Menüyü kapatın.
6. **Recompile** butonuna basarak projeyi tekrar derleyin.

```text
Menu
→ Compiler
→ XeLaTeX
→ Recompile
```

Compiler değişikliği Overleaf tarafından proje ayarlarına otomatik olarak kaydedilir.

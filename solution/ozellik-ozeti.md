# Özellik Özeti — Ne Eklenebilir, Ne İşe Yarar

> **Hazırlayan:** Yasemin
> **Kaynak:** 21 sitenin (`sites/01–21`) 4 turlu inceleme notlarının analizi
> **Detaylı gerekçe:** [`eksikler-ve-cozumler.md`](eksikler-ve-cozumler.md)

---

| Eklenecek Özellik | Ne İşe Yarar |
|---|---|
| **Doğal dil arama** | Kullanıcı "okula yakın 3+1 £300k altı" yazar, sistem filtrelere çevirir → filtre menüsüyle uğraşma bitir |
| **AI ilan özeti + highlights** | Uzun açıklamayı 2-3 madde + öne çıkan noktalar → alıcı 30 saniyede karar verir |
| **İlan Q&A** | "Aile için uygun mu?", "sel riski var mı?" → alıcı danışman beklemeden yanıt alır |
| **Değerleme açıklama katmanı** | Rakamın altına "neden bu fiyat" → satıcı güven duyar, formu tamamlar |
| **Mesai dışı chatbot** | Gece 11'de gelen soruya cevap → kaçırılan lead yakalanır |
| **Lead scoring** | Toplanan form verisi (mortgage, avukat, taşınma zamanı) → danışman en sıcak leadi önce arar |
| **Otomatik randevu (Cal.com)** | "Şu saatte gel" → gerçek rezervasyon, form-tur değil |
| **Bölge/ulaşım verisi** | Postcode → okul, ulaşım, sel, broadband otomatik → elle yazma bitir |
| **Yayın öncesi çelişki denetçisi** | Başlık 2 yatak, detay 3 yatak → yayına gitmeden yakala → hukuki risk azalır |
| **EPC / Floor plan açıklaması** | Görseli sade dile çevir → "D rated = yıllık ~£1,800 enerji" → alıcı sayı görür |
| **PDF rapor özeti** | Scottish Home Report 40 sayfa → 5 madde özet + risk bayrakları → alıcı okur |
| **Fuzzy arama / typo düzeltme** | "Sheilds" → "South Shields" → yanlış sonuçtan kurtulur |
| **Ülke-farkında hesaplayıcı** | İskoçya'da LBTT, İngiltere'de SDLT → hukuki hata bitir |
| **Postcode → şube yönlendirme** | Kullanıcı doğru şubeye otomatik → 11 şubeli sitede kaybolma bitir |
| **Danışman içerik stüdyosu** | Tek girdi → web + portal + sosyal + alt-text → aynı işi 3× yapma bitir |
| **Vision (fotoğraf) değerleme** | Satıcı fotoğraf yükler → anlık ön tahmin → 24 saat bekleme bitir |
| **Sahte "100% MATCH" rozetini kaldır** | Ya sil ya gerçek skor → güven onar |
| **Dormant bileşenleri devreye al** | Chatbot/InstantValuation/StampDuty zaten kodda → config aç → hızlı zafer |

**Tek cümle:** 21 site bugün **veri topluyor ama işlemiyor, rakam üretiyor ama açıklamıyor, formu gösteriyor ama randevuya çevirmiyor** — eklenecek her özellik bu üç boşluktan birini kapatıyor.
